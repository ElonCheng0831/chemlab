# 化境 ChemLab

一个纯静态的中文化学教学网站，收录 **279 条常见化学品与试剂的实验室制法** 与 **210 个化学实验**。每个条目都按同一套结构组织：原理 → 试剂与仪器（带用途标签） → 操作图解 → 操作步骤 → 实验现象 → 结论 → 主要用途（部分条目） → 注意事项，并标注 1–3 级风险。

另有一个 **合成工坊**：拖入一个目标药品，就会自动展开它的全套原料与制法，形成一棵可以逐层查看的配方树；可以标注“这种药品没有”，系统会自动换一条制法，并且同一种药品只展开一次，避免无限套娃。

> 本站只面向教学与科普，不构成操作指导。所有实验都必须在具备资质的实验室、由专业人员指导完成；家庭材料类条目也仅用于理解原理。

## 打开方式

直接双击 `index.html` 即可，无需服务器、无需构建。若希望深链与 `localStorage` 行为更接近线上，可用任意静态服务器托管本目录：

```bash
python -m http.server 8080
```

## 收录内容

**制法（279 条，8 个分类）**

- 气体（18）、单质（12）、氧化物（21）、酸与碱（24）、盐（101）、有机物（56）、试剂与溶液（36）、生活材料（11）
- 酸与碱含硫酸、硝酸、盐酸，以及氢氧化钠、氢氧化钾、氨水、氢氧化铁胶体等；盐类覆盖氯化物、硫酸盐、硝酸盐、碳酸盐、磷酸盐、卤化物与络盐
- 单质（12）：铜、铁、锌、铝、镁、钠、钾、硅、硫、碘等——以还原、电解、置换等教材方法为主；钠、钾明确标注为工业电解/专业演示级别
- 生活材料（11）：紫甘蓝指示剂、蛋壳制碳酸钙、小苏打制纯碱、粗盐提纯、铜与食醋/双氧水制醋酸铜、土豆提取淀粉、橘皮提取柠檬烯、白醋除锈、双氧水制氧、牛奶制酪蛋白塑料等
- 部分药品提供 **替代制法**（如双氧水分解制氧、铝与氢氧化钠制氢、碳酸氢钠与食醋制二氧化碳、粗盐重结晶制氯化钠），工坊“自动换源”会用到它们
- **同离子替代**：同一产物可以换一种盐来提供核心离子，例如硝酸可由硝酸钠或硝酸钾与浓硫酸制得，盐酸可由氯化钠或氯化钾与浓硫酸制得，硫酸铜可由铜、氧化铜或碱式碳酸铜出发。它们共享同一化学式，因此在链路页的“其他配方”和工坊“换源”里会自动归为一组；核心反应相同，副产物与操作细节不同
- **清洁剂与家庭材料**：新增 6 条以常见清洁、除垢用品为原料的制法——小苏打煅烧制碳酸钠、食醋与小苏打制乙酸钠、洁厕灵与蛋壳制氯化钙、生石灰消化制氢氧化钙、柠檬酸除垢剂与小苏打制柠檬酸钠、柠檬酸溶液配制。反应本身是教材级的复分解、中和与煅烧；条目里单独标注了“含氯清洁剂不可与酸性产品混用”的氯气风险，以及废液中和与通风要求

**实验（210 个）**

- 基础操作（21）、物质性质（43）、气体与燃烧（24）、电化学（22）、有机（29）、分离提纯（22）、定量测量（21）、趣味演示（26）、沉淀溶解平衡（1）、配位化学（1）
- 每个实验都带 **难度等级**：基础 84 / 进阶 80 / 挑战 46。按风险等级、步骤数、仪器数量与预计时长综合评定，个别演示（焰色、蓝瓶子、碘钟、铝热等）做了人工校正；卡片与详情页都会显示“难度 N · 基础/进阶/挑战”
- 本轮新增 6 个短视频平台常见的可视化实验：糖水密度彩虹柱、碘熏指纹、叶脉书签、豆浆点卤、紫甘蓝花青素变色、菠菜色素纸层析，均按教学场景重写并补齐风险与废液处理
- 另新增 4 个“安全推进”替代实验：水火箭、气球反冲车、小苏打白醋压力实验、泡腾片压力小实验。它们用压缩空气、水或二氧化碳讲反冲与气体膨胀，不涉及燃烧或含能材料，也不提供任何固体推进剂配方

## 功能

- **合成工坊（自动配方树）**：`forge.html` 左侧是 279 张制法卡片，拖入或点击一个目标药品，画布会自动展开它需要的全部原料：能自制的原料继续向上展开，找不到制法的标为“基础原料”；同一种药品只展开一次，超出 5 层或 64 个节点时自动停止，从结构上避免套娃。节点可拖动、可手动连线，右侧“依赖清单”列出所有中间体与基础原料，并支持 **换源**（改用另一种制法，含替代制法）、**标记缺失**（标红并保留位置）、**定位** 与 **折叠原料**。下方按拓扑顺序列出步骤，风险取全路线最高级；“补足药品”可记录基础原料实际补入的试剂（自动与手动模式都可用），并随路线保存、刷新恢复、写进导出文本。画布自动保存在 `localStorage`（键 `chemlab-forge-v1`）。空白处按住并拖动可平移画布，滚轮同样可横向/纵向滚动；平移不会误触节点点击
- **配方树算法优化**：预建“化学式 → 制法”“名称 → 制法”索引，避免每层都全表扫描；为每条制法估算“到基础原料的层数”，优先选更短、更少绕路的制法；按产物化学式去重，同一物质只保留一个节点；识别“反应使用自身产物”的循环原料并加徽标；列内按子节点重心排序，减少连线交叉；节点先批量挂载再统一布局。以氢氧化铜为例，展开节点从 31 个降到 12 个；279 个目标全部通过“无重复、无环、深度 ≤ 5”的桩测试
- **制造链路视图（点阵工单）**：`preparations.html` 复刻“图鉴 · 制造链路”的阅读方式——顶部深色条放面包屑与搜索，左侧文件夹打开 279 条图鉴抽屉（8 个分类 chips、风险筛选），画布用浅灰物品块表示原料、深色工序条表示操作、右侧产物块收尾，细线加箭头连接，产物下方金色胶囊可切换其他配方；底部“显示比例”滑杆支持 40%–100% 缩放，点节点或工序条打开完整工单
- **盐类离子检索表**：`preparations.html` 顶部的「盐类检索表」按钮（或点分类里的“盐”）会打开一张交叉表：左列是阳离子、顶行是阴离子，单元格显示化学式，同一格有多种制法时显示条数。点击单元格即按药品处理——只有一条制法时直接切到它的制造流程图（与其它药品一致）；同一格有多条时，右侧面板列出可选制法，选一条后再打开对应流程图。表格固定在左侧、不会铺满整屏；对应盐少于 2 种的“少量离子”不单独占行列，统一收在表格下方的「少量离子盐类」里。101 条盐中 95 条带有 `ions` 元数据，复盐、碱式盐、碳化物等 6 条不参与表格，仍可在链路视图和图鉴里查看；搜索框在表格视图下会同时过滤阴阳离子与盐名
- **原料用途标注**：每个原料节点副标题标出它在反应中的角色（主原料 / 氧化剂 / 还原剂 / 催化剂 / 酸化剂 / 沉淀剂 / 溶剂 / 指示剂等），画布下方列出整条链路的“投料用途”标签；详情页“试剂与仪器”同样带用途标签，悬停可看该角色的作用说明。判定优先使用条目自带的 `reagentRoles`，否则按名称关键词推断
- **固体推进剂专题**：`propellants.html` 用纯科普方式解释双基、复合、硝酸盐/糖类与 APCP 等类别，以及比冲、燃速、感度、法规和航天应用；页面明确不提供配方、配比、原料清单、混合、浇注、固化、点火或测试方法，并给出辨伪与应急知识。第六节只列水火箭、气球反冲车等安全替代实验，不提供任何“温和固推”配方或改良建议
- **清洁剂成分表**：`cleaners.html` 归纳 84 消毒液（次氯酸钠）、洁厕灵（稀盐酸）、管道疏通剂（氢氧化钠/浓硫酸/浓盐酸）、除垢剂（柠檬酸/氨基磺酸/盐酸/硝酸）、氧漂、酒精等常见产品的有效成分、典型浓度与混用风险；用反应式说明“酸 + 次氯酸钠 → 氯气”，并逐条核对“红色/黄色 KK 鲨鱼 = 浓硫酸/浓盐酸”“COD 去除剂 = 氯酸钠”“南科除垢剂 = 稀硝酸”等说法：有标签、SDS 或公开检测资料支持的如实写明，同时强调它们属于危险化学品、不能当家用清洁剂，也不提供任何提纯或制备路线
- **操作图解**：`assets/art.js` 用自绘 SVG 画出加热、过滤、蒸发结晶、蒸馏、回流、水浴、气体收集、沉淀、比色、滴定、电解、分液、层析、焰色、高分子、电镀等操作；详情、列表卡片与链路节点都带缩略图
- **索引筛选**：类别 chips 带条目计数，风险等级与关键词搜索叠加生效
- **深浅双主题**：跟随系统偏好，可手动切换，选择写入 `localStorage`（链路页固定浅色工业界面）
- **详情弹层**：原生 `<dialog>`，支持 `Esc` 关闭、点击遮罩关闭
- **深链**：`preparations.html#p/copper-metal` 直接定位链路，`experiments.html#e/iodine-clock` 直接打开工单
- **响应式与无障碍**：桌面双栏 → 手机单列；移动端折叠菜单、盐表改为上下布局（表格横向滑动、结果在下方）、详情弹层改为底部抽屉、工坊调色板与画布纵向堆叠；语义化标签、`aria-*`、键盘可达（工坊节点支持 Delete 删除）
- **打印友好**：打印时隐藏导航与装饰，保留正文与图解

## 如何增改内容

数据与视图完全分离。内置条目在 `assets/data-preparations.js` / `assets/data-experiments.js`，格式如下：

```js
{
  id: "my-item",            // 唯一，用于深链 #p/my-item
  name: "名称",
  formula: "化学式",         // 制法条目使用
  category: "盐",            // 8 类：气体 / 单质 / 氧化物 / 酸与碱 / 盐 / 有机物 / 试剂与溶液 / 生活材料
  hazard: 2,                // 1 低危 / 2 中危 / 3 高危
  duration: "20 分钟",       // 实验条目使用
  summary: "一句话概述",
  principle: ["方程式或原理，一行一条"],
  reagents: ["试剂 1", "试剂 2"],   // 同时是链路里的原料节点
  apparatus: ["仪器 1", "仪器 2"],
  steps: ["步骤 1", "步骤 2"],      // 同时是链路里的操作阶段节点
  observation: "预期现象",
  conclusion: "结论与说明",
  cautions: ["注意事项 1", "注意事项 2"],
  tags: ["高中", "大学"],
  uses: ["主要用途 1", "主要用途 2"],       // 可选：详情页“主要用途”
  reagentRoles: { "浓硫酸 20 mL": "高沸点酸 / 脱水剂" }, // 可选：覆盖原料用途标注
  ions: ["Na⁺", "Cl⁻"],      // 可选（盐类）：阳离子、阴离子，用于盐类检索表
  difficulty: 2,            // 实验条目使用：1 基础 / 2 进阶 / 3 挑战
  art: "distill"            // 可选：指定操作图解，见 assets/art.js
}
```

原料用途标注的默认规则写在 `assets/app.js` 的 `ROLE_RULES`：按“催化剂、脱水剂、氧化剂、还原剂、酸、碱、沉淀剂、溶剂、指示剂、络合剂、保护气、电极、助熔剂”的顺序匹配名称关键词，未命中则标为“反应原料”。需要精确说明时，用 `reagentRoles` 指定，键名可以是原料名的片段。

### 本地手写条目（可选）

`assets/add-content.js` 提供了一个不依赖界面的本地方案：直接往 `window.CHEMLAB_ADDONS` 里写对象，刷新页面即会合并进列表、筛选、链路、工坊与深链。

```js
window.CHEMLAB_ADDONS = {
  preparations: [
    { name: "示例制法", category: "无机物", hazard: 1, steps: "第一步\n第二步" }
  ],
  experiments: [
    { name: "示例实验", category: "趣味演示", hazard: 1, duration: "10 分钟", steps: ["第一步"] }
  ]
};
```

- 只需 `name` 与至少一步 `steps`，其余字段自动补默认值；空缺的 `summary` 会在页面左下角提示。
- `id` 自动生成（`custom-p-xxxxxx` / `custom-e-xxxxxx`），也可显式提供；重复时自动追加 `-2`、`-3`。
- 浏览器 `localStorage` 中键名 `chemlab-addons` 的条目也会被合并。

## 技术说明

- 纯原生 HTML + CSS + JavaScript，无构建步骤、无框架、无运行时依赖；唯一的第三方脚本是百度统计（`assets/analytics.js`，可整行删除或删除该文件停用）
- 全部样式使用 CSS 自定义属性，`data-theme="light|dark"` 切换主题
- 工坊使用 Pointer Events 与 HTML5 拖放：预建化学式/名称索引，按“到基础原料的最短层数”挑选制法，以“产物化学式 + 消耗它的物质”为展开键去重，深度上限（5）与节点上限（64）兜底；连线用 SVG 贝塞尔曲线，路线顺序为 Kahn 拓扑排序；换源记录（键为“药品 id|序号”）与补足药品记录（基础原料键为 `raw>原料名`，手动衔接为“上一步节点键 > 下一步节点键”）都随路线持久化
- 图解全部为内联 SVG 线稿，跟随主题变色，不依赖外部图片与版权素材
- 页面首屏内联主题初始化脚本，避免深色模式闪白
- 已做静态校验：JS 语法、数据 id 唯一性与字段完整性（279 + 210 条）、同离子替代分组（硝酸 2 条、盐酸 2 条、碳酸钠 3 条、硫酸铜 3 条等）、8 类合法性与 `ions` 覆盖（101 条盐中 95 条）、实验难度分布（84 / 80 / 46）、7 个页面 HTML 标签/资源/导航/id、3 个 CSS 括号平衡；DOM 桩测试覆盖工坊自动展开、缺失标记与换源、画布空白平移、链路抽屉与缩放，以及盐表交互（单制法单击直接进入流程图、多制法列出选项、选中后切换、搜索回车不会命中已删除函数）
- 当前环境无头浏览器被沙箱拦截，视觉层以静态推演与结构校验为准，未做截图回归

## 访问统计

站点使用百度统计（站点 ID `6cebbb2925bb504430e93a97a47e10e9`）记录访问量、来源与停留时间。加载逻辑在 `assets/analytics.js`，7 个页面都在 `</head>` 前引用它。

- 仅在 `http:` / `https:` 下加载；本地双击 `file://` 打开不会上报，避免污染线上数据。
- 统计脚本来自 `hm.baidu.com`，广告拦截插件会拦截它，因此统计数会低于真实访问量。
- 百度统计会收集 IP、User-Agent、来源与页面行为等信息；如果用于公开站点，建议在页脚或隐私说明中注明“本站使用百度统计”。本站目前写在 README 中，页脚未单独加声明。
- 需要停用时，删除各页面里的 `<script src="assets/analytics.js"></script>` 即可，其余功能不受影响。

## 内容边界与安全声明

本站**只面向教学与科普**，所有内容以基础化学教材与常规实验讲义为依据整理，目的是讲清原理、现象与风险，而不是提供操作指南。

- 涉及有毒气体、重金属、强腐蚀试剂的操作都需要通风橱、个人防护与合规的废液处理。
- **关于“生活用品制浓硫酸”的网传说法**：把双氧水、糖果或饮料加热，既不能引入硫元素，也不可能得到浓硫酸。红色通渠剂本身可能就是浓硫酸，加双氧水的作用是氧化掉其中的染料/指示剂、让颜色褪去，这是“它已经是强酸”的旁证，不是制备；向浓硫酸中加双氧水会放热并可能生成过氧硫酸，极其危险，不能模仿。双氧水受热只会分解为水和氧气；浓硫酸的工业制备需要硫或硫化物 → 二氧化硫 → 催化氧化 → 三氧化硫 → 浓硫酸吸收，涉及高温、催化剂与强腐蚀条件，家庭环境完全不具备。本站不提供任何此类“家庭制备”内容；相关的安全原理见 `safety.html`。
- **关于固体推进剂**：`propellants.html` 只做分类、能量原理、应用与法规的科普，不提供硝糖、APCP 或任何含能材料的配方、配比、原料清单、混合、浇注、固化、点火与测试方法。个人自制、储存、点燃固体推进剂既极其危险，也可能触犯法律；相关话题请在具备资质的教学或科普语境中讨论。
- **关于清洁剂成分与网传对应**：`cleaners.html` 归纳有标签、SDS 或公开检测资料支持的常见有效成分，并强调浓度以产品标签为准。84 消毒液与洁厕灵混用会放氯气，这是有明确反应式的危险事实；红色/黄色 KK 鲨鱼是管道疏通剂，分别有浓硫酸/浓盐酸体系的产品，COD 去除剂常以工业氯酸钠为主成分，南科除垢剂有资料指向稀硝酸——这些“成分对应”成立不等于可以家用，浓硫酸、浓盐酸、硝酸与氯酸钠都属于危险化学品，页面不提供任何用清洁剂制备、提纯或浓缩强酸的路线。
