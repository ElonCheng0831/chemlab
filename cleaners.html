清洁剂里到底有什么

84、洁厕灵、管道疏通剂、除垢剂、氧漂、酒精——它们的有效成分大多是本站已经讲过的酸、碱、氧化剂或盐。 这一页把常见产品的典型成分、浓度范围与混用风险放在一起，并逐条核对网传的“颜色对应浓酸”说法。

一句话：酸 + 含氯消毒剂 = 氯气。 84 消毒液（次氯酸钠）与洁厕灵（盐酸）混用会放出黄绿色、有刺激性气味的氯气；在卫生间这类小空间里，短时间内即可达到伤害浓度。 任何“先倒一点、再倒一点”的混用都不要做。若已经混用，立即离开、开窗通风，不要返回“看看反应”，并拨打急救电话。

一、先学会看标签，而不是看颜色

同一种清洁剂，不同品牌、不同型号的成分与浓度可能完全不同。判断依据应当依次是： 产品成分表 → 执行标准 → 安全技术说明书（SDS）→ 危险象形图与警示语。 颜色、香味、包装上的水果或卡通图案都不构成成分信息；把清洁剂倒进饮料瓶、食品罐，是家庭中毒最常见的原因之一。

  • 浓度：标签上的“有效氯”“盐酸含量”“NaOH 含量”通常以质量分数或 g/L 表示，稀释倍数必须以标签为准。
  • 禁止混用：标签上出现“切勿与酸性/含氯产品混用”时，不是建议，是硬性禁止。
  • 危险象形图：腐蚀（GHS05）、氧化（GHS03）、急性毒性（GHS06）、易燃（GHS02）分别对应完全不同的处置方式。

二、常见清洁剂的典型成分

产品类型常见有效成分典型浓度 / 形态关键风险
84 消毒液 次氯酸钠 NaClO（碱性） 有效氯约 4%–7%，液体，使用前稀释 遇酸放氯气；遇氨放氯胺；遇热分解；腐蚀金属与织物；不可与酒精混用
洁厕灵 盐酸 HCl + 表面活性剂 盐酸约 5%–10%，酸性 与含氯消毒剂混用放氯气；腐蚀大理石、水泥、金属；溅入眼内可致伤
管道疏通剂 氢氧化钠 NaOH 或氢氧化钾 KOH 固体颗粒或高浓度液体 遇水强烈放热、可沸腾喷溅；遇铝放氢气；对皮肤和眼睛强腐蚀
水垢 / 除垢剂 柠檬酸、氨基磺酸、磷酸，部分强效产品用盐酸 酸性液体或固体，pH 常低于 2 与含氯消毒剂混用放氯气；腐蚀金属与天然石材

厨房重油污净 NaOH、表面活性剂、醇醚溶剂 碱性液体或泡沫 碱性腐蚀；与酸混用放热；与含氯产品混用可能放氯气
玻璃水 甲醇、乙醇或异丙醇 + 表面活性剂 液体，甲醇型常见 甲醇有毒、易燃；误饮可致失明；不可靠近明火
除霉剂 次氯酸钠，或季铵盐类 液体 / 泡沫 含氯型遇酸放氯气；季铵盐型不可与阴离子表面活性剂混用
COD 去除剂 工业水处理剂，成分差异很大：过硫酸盐、过氧化氢、次氯酸盐等 固体或液体，按工业标签使用 强氧化性；不可与还原剂、有机物随意混合；属于工业化学品，不应按家用清洁剂对待

表中浓度是常见范围，不是产品承诺。具体数值以你手里那瓶的标签和 SDS 为准。

三、逐条核对网传的“成分对应”

这些说法里，84 消毒液与洁厕灵的主要有效成分基本正确；COD 去除剂、KK 鲨鱼通渠剂、南科除垢剂也各有标签、SDS 或公开检测资料支持其“强酸/氯酸盐”身份。 但“成分对得上”不等于“可以家用”，更不等于“可以自己提纯”。下面逐条说明证据强度与风险：

网传说法核对结论说明
84 消毒液 = 次氯酸钠 正确 有效成分是 NaClO，溶液显碱性。不同品牌的有效氯差异较大，使用前必须按标签稀释。
洁厕灵 = 稀盐酸 多数正确 多数洁厕灵以 5%–10% 盐酸去水垢，另含表面活性剂与香精；也有用柠檬酸或氨基磺酸的“无盐酸”产品，仍需看标签。
COD 去除剂 = 不纯的氯酸钠 有依据，但不能一概而论 工业“COD 去除剂/屏蔽剂”常以氯酸钠 NaClO₃ 为主成分，常为工业级、含杂质；也有过硫酸盐等体系。它主要靠干扰酸性高温消解时的测定，并非真正降解 COD，用于篡改监测数据属于违法。
红色 KK 鲨鱼 = 浓硫酸 产品确有此类，但极其危险 “KK 鲨鱼”是管道疏通剂（通渠剂）品牌，不是食品或糖果。红色产品以浓硫酸为卖点的情况在市面上存在，浓度可达 90% 以上；红色常来自染料或酸碱指示剂，加双氧水可把色素氧化掉、让液体褪色，但这只是“它已经是强酸”的旁证，不是制酸。倒进管道会剧烈放热、沸腾喷溅，遇水、碱、含氯消毒剂都极度危险。
黄色 KK 鲨鱼 = 浓盐酸 产品确有此类，但极其危险 黄色通渠剂常为浓盐酸体系，开盖即可放出氯化氢气体，腐蚀金属与水泥，与 84 消毒液混用会立刻放氯气。它不是家用洁厕灵，不能按“多倒一点更通”使用。
南科除垢剂 = 稀硝酸 有检测资料指向硝酸，但批次差异大 公开资料与使用者检测多指向稀硝酸体系，但浓度、配方随批次和用途变化，必须以标签/SDS 为准。硝酸是强氧化性酸，会腐蚀铜、铁等金属，与有机物、还原剂接触可能剧烈反应，不应自行分馏提纯。

资料依据：产品标签与安全技术说明书（SDS）；环境行业对 COD 去除剂主成分的公开报道；以及公开检测帖对通渠剂、除垢剂酸体系的测定。浓度与配方会随批次变化，具体以手中产品标签为准。

关于“红色 KK 鲨鱼 + 7% 双氧水加热制浓硫酸”。 这个说法把“验证”和“制备”混在了一起：红色通渠剂本身可能就是浓硫酸，而双氧水不能提供硫元素，只会分解成水和氧气，不可能把别的物质“变成”硫酸。 至于为什么要加双氧水——红色通渠剂常加染料或酸碱指示剂来着色，双氧水可以把色素氧化掉、让液体褪色，这个动机解释是成立的，但它只是“这瓶液体已经是强酸”的旁证，不是制酸步骤。 对浓硫酸再加双氧水并加热，会放热并可能生成过氧硫酸（Caro 酸），酸雾喷溅、氧化性增强，密闭或接触有机物时尤其危险；想把稀硫酸提浓到 98%，需要 338 ℃ 的专门蒸馏设备和耐腐蚀冷凝系统，家庭条件既做不到，也不应该尝试。所以这页只解释成分与褪色原理，不提供操作步骤。

四、最危险的几种混用

混合反应与产物后果
84 消毒液 + 洁厕灵NaClO + 2HCl → NaCl + Cl₂↑ + H₂O黄绿色氯气，强烈刺激呼吸道，小空间内可致化学性肺炎
84 消毒液 + 氨水 / 含氨清洁剂生成氯胺刺激性气体，损伤肺组织
84 消毒液 + 酒精生成乙醛、氯仿等副产物刺激性蒸气，反应放热，密闭容器有超压风险
管道疏通剂 + 铝制品2Al + 2NaOH + 6H₂O → 2Na[Al(OH)₄] + 3H₂↑氢气积聚，遇火源可燃可爆
强酸 + 强碱中和，大量放热沸腾、喷溅，热液与酸雾伤人
硝酸 / 过氧化氢 + 有机物强氧化反应可能自燃、爆燃；废布、纸屑不要随手丢进氧化剂

五、如果已经混用或溅到身上

  • 吸入气体：立即离开现场到通风处，保持安静；出现咳嗽、胸闷、呼吸困难，拨打急救电话并说明可能接触氯气。
  • 皮肤接触：脱去污染衣物，用流动清水冲洗至少 15 分钟；强酸、强碱灼伤不要自行涂抹药膏。
  • 眼睛接触：立即用洗眼器或流动清水冲洗至少 15 分钟，翻开眼睑，随后就医。
  • 误饮：不要催吐，不要用酸碱中和“自救”；携带产品标签或 SDS 立即就医。
  • 不要返回现场：关闭房门、开窗通风，等专业人员处理；氯气比空气重，低洼处浓度更高。

六、把成分和站内条目连起来

这些清洁剂的有效成分，在站内都有对应的制法、性质与安全条目。想弄清反应原理，可以从这里继续：

  • 次氯酸钠溶液：84 消毒液的有效成分，碱性、强氧化性。
  • 盐酸与硫酸：洁厕灵与工业强酸的对照。
  • 氢氧化钠：管道疏通剂与重油污净的碱性来源。
  • 柠檬酸溶液：温和除垢剂的做法与浓度说明。
  • 氯气的溶解性与氯水性质：理解“酸 + 84”为什么危险。
最实用的一条规则：一种清洁剂只做一件事。 不要为了“更干净”把两种产品倒在一起；不要用饮料瓶分装；不要把清洁剂放在食品、糖果旁边。 需要除垢就用除垢剂，需要消毒就用稀释后的消毒剂，中间用清水冲干净。
